# Netflix Movies and TV Shows Data Analysis

## Project Overview
This project explores a Netflix Movies and TV Shows dataset using Python. The goal is to analyze content distribution, genres, countries, release years, and movie durations.

## Tools & Technologies
- Python
- Pandas
- Matplotlib

## Analysis Performed
1. Data loading and exploration
2. Missing value analysis and handling
3. Movies vs TV Shows distribution
4. Top 10 countries by content count
5. Content release year analysis
6. Average, maximum, and minimum movie duration
7. Top 10 Netflix genres

## Key Findings
- Movies account for approximately 69.62% of the titles.
- TV Shows account for approximately 30.38%.
- 2018 has the highest number of titles by release year in the analyzed dataset.
- The average movie duration is approximately 99.58 minutes.
- International Movies is the most common genre category.
